# 재난문자 이미지 인식 계약

## 범위

- 공개 재난문자 목업의 JPEG 또는 PNG 이미지만 입력한다.
- 이미지에서 한국어 재난문자 본문을 전사하고 `TYPHOON`, `EARTHQUAKE`, `COLD_WAVE`, `FIRE` 중 하나로 분류한다.
- 기존 환자 상태 해석, 대응방법 작성, 문자 문구 생성의 세 AI 역할은 변경하지 않는다. 이미지 인식은 재난 입력 전처리 단계다.
- 이미지에 존재하지 않는 지역, 발령·종료 시각, 심각도는 생성하지 않는다.
- 인식 결과는 `PROPOSED`, `reviewRequired: true`이며 그 자체로 Backend A 재난을 활성화하지 않는다.

## 안전 조건

- 최대 4 MiB이며 파일 MIME 형식과 JPEG/PNG 시그니처가 일치해야 한다.
- 환자 이름, 전화번호, 주소 등 직접 식별정보가 들어간 이미지를 입력하지 않는다.
- SDK 오류, 빈 응답, 잘못된 JSON, 지원되지 않거나 모호한 재난 유형은 안전한 오류 코드로 거부한다.
- API 할당량 초과는 공급자 오류 원문을 노출하지 않고 `GEMINI_RATE_LIMITED`로 구분한다.
- Gemini 요청이나 전체 이미지·프롬프트를 로그로 남기지 않는다.
- 행동 코드는 Gemini가 만들지 않고 Core의 재난 유형별 허용 목록에서 선택한다.

## 테스트 경계

`npm test`에서는 SDK를 Mock 처리해 실제 Gemini와 SOLAPI를 호출하지 않는다. 실제 이미지 확인은 명시적인 smoke 명령으로만 수행한다.
