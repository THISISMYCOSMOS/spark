# AI 환자별 재난 대응방법 계약

## 책임 분리

- 규칙 엔진: 재난 유형과 가입 시 등록된 환자 상태로 내부 허용목록의 대응 코드를 결정한다.
- AI: 결정된 코드와 설명만 자연스러운 한국어 안내문으로 정리한다.
- 운영자: 결과가 항상 `status: PROPOSED`, `reviewRequired: true`이므로 승인 후 사용한다.

AI가 새로운 대응 행동을 결정하거나 진단·처방·약 변경·의료기기 설정 변경을 지시하지 않는다. AI 호출 실패나 안전 검증 실패 시 허용목록 설명을 연결한 `RULE_FALLBACK` 문구를 반환한다.

## AI에 전달되는 정보

- 의료기기 유형 코드, 전원 의존도 코드, 이동·소통 지원 여부
- 배터리·검증된 보조전원·안전 버퍼·남은 안전시간 수치
- 재난 유형·심각도·지역코드·발생/종료 예상 시각·공식 안내 코드
- 규칙 엔진이 고른 대응 코드와 승인된 설명

환자 이름, 전화번호, 주소, 응답 URL, 가입 자유서술은 보내지 않는다.

## 안전 경계

현재 카탈로그는 개발용 내부 허용목록이며 의료·재난 담당자의 운영 승인을 대신하지 않는다. 운영 전 국내 재난 행동요령, 각 의료기기 제조사 사용설명서, 기관별 비상계획에 맞춰 버전 승인해야 한다. 의료기기 전원·침수 관련 공통 경계는 [FDA 자연재난 의료기기 안내](https://www.fda.gov/medical-devices/emergency-situations-medical-devices/fda-offers-tips-about-medical-devices-and-natural-disasters)를 참고했다.
